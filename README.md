Name of my project is "KeenKeeper".
KeenKeeper is a personal relationship and contact management platform designed to help users track and nurture their most meaningful connections. Acting as a "digital shelf" for relationships, it allows users to maintain a detailed history of interactions, ensuring that important friendships and professional bonds are never neglected.

Technologies Used
The project is built using a modern web development stack:

React.js: For building a dynamic user interface and component-based architecture.

Tailwind CSS: For creating a custom, modern, and highly responsive design.

DaisyUI: Utilized for sleek UI components like dropdowns, buttons, and modals.

React Context API: For efficient global state management and data handling.

React Router: For seamless client-side navigation between pages.

React Icons (Lucide/Fi): For an intuitive and interactive visual experience.

Key Features
Categorized Timeline Filtering:
Users can view a complete history of interactions (Calls, Videos, Texts) in a structured timeline. An integrated dropdown filter allows for quick sorting to find specific types of activities instantly.

Visual Interaction Tracking:
The platform features dynamic visual indicators (such as progress circles or charts) that display the distribution of communication methods. This helps users understand the depth and frequency of their engagement with each contact.

Responsive Personal Dashboard:
A fully optimized dashboard that provides a comprehensive view of individual profiles, contact details, and conversation history. The design ensures a smooth experience across mobile, tablet, and desktop devices.
